## Project Overview

This project focuses on **esports earnings and competitive gaming**. Esports tournaments generate large amounts of digital data, including prize pools, number of players, and number of tournaments. The goal of this project is to explore how esports data can be organized, analyzed, and interpreted as a form of digital culture.

Throughout the semester, this project will build datasets and use computational tools to better understand trends in competitive gaming.

---

## Current Progress

### Initial Dataset

For the first stage of the project, I created a **dataset of 75 esports games**. The dataset was created by auditing and augmenting an existing esports dataset and adding additional metadata.

New fields added include:

- `RegionPopularity`
- `CompetitiveLevel`
- `Notes`

Python and the Pandas library were used to load the original dataset, sample games across different genres, and generate the new dataset.

---

## Dataset Fields

The dataset includes the following information:

- Game
- ReleaseDate
- Genre
- TotalEarnings
- TotalPlayers
- TotalTournaments
- RegionPopularity
- CompetitiveLevel
- Notes

This dataset helps describe how different games contribute to the esports ecosystem.
